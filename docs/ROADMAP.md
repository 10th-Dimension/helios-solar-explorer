# Roadmap

This records bounded implementation status, not a release schedule. Included behavior does not imply every extension or device passed acceptance.

## Included in the sourced exploration update

| Theme | Implemented | Remaining limit |
| --- | --- | --- |
| Major moons / nearby systems | Moon, Europa, Titan and Enceladus facts, parent navigation and size comparison; captured TRAPPIST-1/GJ 1132 reference rows | No new moon globes/live ephemerides; extra archive hosts remain reference-only, with no invented spatial placement. |
| Catalog / labels | 24-result pages, scroll/focus/filter fixes and spatial-bin overlap lookup | Not full virtualization or unlimited label legibility; no measured FPS gain. |
| Epoch / uncertainty | Julian epochs 1900–2100, component-wise missing-motion and scalar-error disclosures | No full covariance, general binary acceleration or precision ephemeris. |
| Teaching | Prediction/explanation workbench, moon comparison and improved written lesson fallback | Notes are temporary; no new grading/account system or classroom certification. |
| Sirius fit | Published relative B–A elements and epoch-aware J2000 sky projection | No invented depth, absolute barycenter or covariance envelope. |
| Lighting / ring shadows | Host-directed illumination and Saturn annulus/gap intersections shading its globe | Albedo, ring opacity and display scale remain illustrative; not radiative transfer or climate simulation. |
| Performance / streaming | Optional nonblocking GPU timing and bounded local CPU/resource diagnostics | Full bottleneck profiling, RTX 4050 measurements, streaming and extended leak tests remain unfinished. |
| Observed weather | Four cached SDO/AIA 304 Å frames with actual UTC times, IDs, headers and hashes | Not continuous/live coverage, calibrated intensity analysis, observed 3D aurora or a forecast. |
| Quality | Expanded deterministic checks, browser regressions and no-3D recovery | Not every instance/device/reset path, screen-reader conformance or prolonged resource behavior. |

See [implementation, sources and verification](ROADMAP_IMPLEMENTATION.md) and [the changelog](../CHANGELOG.md).

## Next evidence-driven work

1. Complete GPU/main-thread profiling in the intended browser and reported renderer; compare Intel Arc and RTX 4050 only when both are actually measured.
2. Finish the real-3D/reset, physical input, reduced-motion and assistive-technology matrix, keeping isolated/controller evidence distinct from live rendering.
3. Establish long-session allocation/disposal bounds before selecting streaming changes.
4. Expand sourced system detail only when epoch/frame, provenance and missing-data policies support it.

## Explicit non-goals for now

No complete galaxy census, precision spacecraft navigation, physically faithful interstellar propulsion, real-time ephemerides, speculative habitable-world claims or invented observed exoplanet surfaces. A larger catalog must not erase existing content or weaken provenance.
