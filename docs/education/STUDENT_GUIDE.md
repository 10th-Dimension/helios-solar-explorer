# Student quick start

You do not need an account or an API key. Your teacher may provide a hosted address, or the project can be [run locally](../../README.md#run-locally).

1. Open **EDUCATION** and choose a lesson.
2. Read the stage's short explanation and learning task.
3. Use its travel or inspection control to visit the relevant object in the existing 3D scene. When a task asks for an interior region, select that region through the interior controls.
4. If the visual interaction is unavailable or unsuitable, open **Read a nonvisual alternative**, read it, and select **Use this alternative for this stage**. It teaches the same concept without requiring you to interpret the canvas.
5. Answer the question. Read the explanation, including after a wrong answer, and retry if needed.
6. Use **Next stage** until the completion screen. You can **Pause**, **Resume lesson**, **EXIT** to free exploration, choose **Lesson library**, or restart a lesson to revisit it.

## Moving around

- Drag to orbit or look around. Scroll or pinch to approach.
- Select an object or its name, or use **WORLDS** and **CATALOG**.
- Use **INFO** for a world story and **INTERIOR** for the modeled cutaway.
- Use **SYSTEM** or **HOME** to recover your bearings.
- Keyboard users can reach controls with Tab and activate them with Enter or Space. Scene movement keys only work when an input or button is not using them. The text alternative avoids needing to aim at a canvas object.

**Escape** closes the current overlay or backs out of an interaction. Focus indicators show which control will respond to the keyboard. If motion is uncomfortable, enable your operating system's reduced-motion setting and use the text alternative.

## Reading the science

The confidence label describes a particular claim, not whether an object looks convincing:

| Label | Meaning |
| --- | --- |
| Measured | Evidence comes from observations or instruments, usually with limits and uncertainty |
| Inferred | Scientists use observations and models to estimate something that cannot be directly measured in the same way |
| Uncertain | Important competing interpretations or large uncertainty remain |
| Unknown | Adequate information is absent; unknown is not zero |
| Illustrative | A teaching or artistic choice, such as compressed distance or a guessed phase |

Open **Evidence** or a source disclosure to see the claim, source, confidence and dates. A source retrieval date is not the date a star was observed. The stellar and exoplanet catalogs are preserved snapshots, not a live feed.

## Remember

The Sun's orange exterior is an explicitly false-color ultraviolet illustration. The inside views are simplified models. Exoplanet surfaces are illustrative, and confirmation does not mean a planet's surface was photographed. Distances, body sizes, orbital phases and animation time are adjusted for navigation. Use the displayed scientific quantities and sources instead of measuring pixels or animation speed.

## Your progress and privacy

One current lesson attempt and the completed-lesson markers are stored only in this browser when local storage is available. Starting or restarting a lesson replaces the unfinished current attempt; this is not a separate saved attempt for every lesson. If unfinished progress would be lost, choose **Start and replace current progress** or **Keep current lesson** at the confirmation. Progress is not sent to a school dashboard. Shared computers may retain earlier progress, so restart a lesson before beginning a new attempt. **Delete saved lesson progress** in the lesson library asks for confirmation before clearing it. Clearing browser site data also clears saved progress. Private-browsing or blocked-storage settings may prevent progress from surviving a reload; you can still use the current lesson.

## If something goes wrong

Use **HOME** or **SYSTEM**, close extra overlays and select a lower graphics quality. If the scene does not render, continue with the lesson's text alternative and tell your teacher which browser and device you used. Do not send anyone passwords, tokens or personal information in a bug report.
